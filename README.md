玄鉴 · 依经据典的术数推演
一个纯静态的中文术数站点：周公解梦、择日吉凶、四柱八字、六爻纳甲、梅花易数、紫微斗数、河洛理数、手相、面相、《道德经》全文。

设计原则只有一句：凡推算必列过程，凡引文必标出处，凡属推演必注明方法。

一、如何打开
双击 index.html 即可，不需要服务器、不需要联网、不需要 npm install。

全部代码为 ES5 风格的原生 JS，经 <script> 直接加载；没有构建步骤，也没有任何外部依赖（字体用系统楷体/宋体回退）。
所有计算都在浏览器本地完成，不采集、不上传任何输入（生日、手相选项等只存在于当前页面内存中，刷新即失）。
如果浏览器禁止 file:// 读取本地脚本（少见），在本目录跑一条命令即可：

python -m http.server 8000
然后访问 http://localhost:8000/。

三、算法要点（可复核）
历法（assets/js/lib/calendar.js）

节气：Meeus《天文算法》第 25 章太阳视黄经（含光行差、章动近似），牛顿迭代求 15° 整倍数时刻，ΔT 用 NASA 多项式。
干支：儒略日数定日柱（锚点：1949-10-01 为甲子日），年柱以立春换年，月柱用五虎遁、时柱用五鼠遁，月令以节（非中气）为界。
真太阳时：均时差 9.87sin2B − 7.53cosB − 1.5sinB + 经度时差。
建除十二神：月支与日支相对位置；黄道六神为除、危、定、执、成、开。
四柱（bazi.js）

五行力量：天干权重（年 1.0 / 月 1.2 / 日 1.0 / 时 1.0）、地支权重（年 1.0 / 月 2.5 / 日 1.2 / 时 1.0），地支按藏干比例分摊（三藏 0.6/0.25/0.15，二藏 0.7/0.3）。
用神三路：扶抑（同党占比定强弱）、格局（《子平真诠》月令取格 + 相神）、调候（冬火夏水，寒暖为急）；候选取用须 占比 + 透干4 + 有根3 ≥ 6，避免取到气绝之五行。
从格/专旺：同党 ≤18% 且日主无根 → 从格；≥82% → 专旺。
大运：阳男阴女顺、阴男阳女逆，三日折一年（差值天数 ×4 个月）。
六爻（liuyao.js）

八宫卦序由「本宫→逐爻变→游魂→归魂」生成，世应定位；纳甲用京房纳甲表；六神依日干起；旬空取日柱旬空。
断卦以月建、日辰为主，兼看动爻、变爻回头生克、用神持世、世应生克、六冲六合、旬空；用神不上卦则取本宫纯卦同位为伏神。
梅花（meihua.js）

先天数 1乾 2兑 3离 4震 5巽 6坎 7艮 8坤；上卦＝(年支数+月+日) mod 8，下卦＝再加时支 mod 8，动爻＝总数 mod 6。
体用：动爻所在为用、另一为体；互卦取 2·3·4 与 3·4·5 爻；变卦动爻取反。
紫微（ziwei.js）

命宫 (2+(月−1)−时支) mod 12，身宫 (2+(月−1)+时支) mod 12；五行局取命宫干支纳音。
安紫微：q=⌈日/局⌉，r=q×局−日，pos=2+q−1，r 偶顺行、奇逆行；天府 (4−紫微) mod 12。
十四主星按紫微系、天府系相对位置安放；四化依年干。
河洛（heluo.js）

天干配河图数（木三八、火二七、土五十、金四九、水一六，阳干取奇阴干取偶），地支配洛书数（子1亥6、巳7午2、寅3卯8、申9酉4、辰戌5、丑未10）。
天数＝奇数之和，地数＝偶数之和；天数除 25、地数除 30 取余；「遇十不用」；数→卦「一坎二坤三震四巽五寄宫六乾七兑八艮九离」。
阳男阴女天卦在上（余类推）；先天卦六爻俱变、内外互移得后天卦。
四、数据来源与校验
六十四卦（data/hexagrams.js）：卦辞、彖、象、386 条爻辞（含乾坤用九用六）逐卦取自维基文库 周易/<卦名> 原文，经传合计 13,848 字；已校验 64 个 binary 互异且覆盖全部六位组合（排除上下卦错位）、卦序符号 = U+4DC0+(n−1)、爻名与阴阳位一致。
周公解梦（data/dreams.js）：382 条、863 关键词，其中 310 条为七言歌诀原文，逐字取自通行本《周公解梦》；每条标明「原典 / 通行 / 演绎」，不混原文与演绎。
道德经（data/daodejing.js）：王弼本八十一章、5,297 字，取自维基文库并剔除王弼注文（第 45 章源页掺入的他本异文已改回通行本）。
农历（lib/lunar.js）：1900–2100 共 73,384 天，已与 lunar-javascript 逐日交叉验证一致。
五、诚实的边界
节气误差数分钟：视黄经算法精度约 1 角分，实测 2024 年各节气与官方值差 2–9 分钟。恰在交节前后数分钟出生者，月柱可能与官方万年历不同，页中已提示。
紫微亮度：诸星「庙旺利陷」传本互异（《全书》与《全集》即不同），本站不冒充一家之表，改以星曜五行 × 宫位五行生克判得地，星名后注明，页中亦明言属推演。
河洛元堂：原法于阴阳时、重数、乾坤特例皆有细例，本站取简法（依生时阴阳择爻），页中已注明「只作参考」。求数之法传本亦有出入（有以天干配洛书者、有专用太玄数者），页中列出全部过程并说明所依。
相术：只有《冰鉴》两句加引号为可查原文（「一身精神，具乎两目；一身骨相，具乎面部」「目者面之渊，不深则不清；鼻者面之山，不高则不灵」），其余一律标「相书通说」，不冒充某书原句。
解梦：属民间辑本系统，非严格经典，页中标「原典/通行/演绎」三档并注明版本。

七、如何复验
内核与数据都可在 Node 下直接 require，无需浏览器（在本目录下执行）：

const cal = require('./assets/js/lib/calendar.js');
const bz  = require('./assets/js/lib/bazi.js');
console.log(cal.fourPillars(new Date(1949, 9, 1, 10, 0), {})); // 己丑 癸酉 甲子 己巳
console.log(bz.analyze({ date: new Date(1990, 5, 17, 10, 30), gender: '女' }).sections[0].body);
../_qa/ 下另有一套假 DOM 冒烟测试（沙箱内浏览器不可用时的替代），在上级目录执行：

node _qa/smoke.cjs         # 12 页渲染 + 检索 + 断言（当前 0 problems）
node _qa/dump.cjs          # 导出每页 HTML 到 _qa/page-*.html 供人工比对
node _qa/peek.cjs          # 去标签打印正文
node _qa/audit-classes.cjs # 页面用到的 class 是否都已定义（查样式遗漏）
node _qa/audit-ziwei.cjs   # 紫微盘 13 格与十二宫方位定位
node _qa/audit-svg.cjs     # 掌图/面相图坐标是否越出 viewBox
本环境沙箱禁止命名管道，Chromium/Edge 的 headless 一律 Check failed 退出，故没有做过真实浏览器截图：以上为结构级验证（渲染无异常、无 undefined/NaN、class 无遗漏、坐标在框内）。若你在浏览器中看到版式异常，多为 CSS 细节，可直接改 assets/css/style.css。

八、引文与推演的区分约定
<em> 引号内、或标注「出处」的句段 —— 古籍原文，逐字可查。
未加引号而标「依法推演」「相书通说」「依某书之义」者 —— 依经义的推断，不冒充原文。
每个断语块右下角均有依据行（《子平真诠·论建禄月劫》 之类），页尾统一附「关于准确性」声明。
