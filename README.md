# 玄鉴 · 依经据典的术数推演

一个**纯静态**的中文术数站点：问事、择日吉凶、四柱八字、六爻纳甲、梅花易数、紫微斗数、河洛理数、**测字**、周公解梦、手相、面相、《道德经》全文。

顶部搜索框与「问事」页可把一句白话（「下月能升职吗」）交给最相干的术数去断，并在结论之后附一段**现代白话解释**。

设计原则只有一句：**凡推算必列过程，凡引文必标出处，凡属推演必注明方法。**

---

## 一、如何打开

双击 `index.html` 即可，不需要服务器、不需要联网、不需要 `npm install`。

- 全部代码为 ES5 风格的原生 JS，经 `<script>` 直接加载；没有构建步骤，也没有任何外部依赖（字体用系统楷体/宋体回退）。
- 所有计算都在浏览器本地完成，**不采集、不上传任何输入**（生日、手相选项等只存在于当前页面内存中，刷新即失）。

如果浏览器禁止 `file://` 读取本地脚本（少见），在本目录跑一条命令即可：

```
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

### 放到手机上

三条路，按「要不要联网」挑一条：

**甲 · 同一 Wi-Fi（最省事，推荐）**
电脑上双击 `手机访问.cmd`（或在站点目录执行 `node serve.cjs`），窗口会打印形如
`http://10.89.67.161:8080/` 的地址；手机连同一个 Wi-Fi，浏览器地址栏输入该地址即可。
电脑关机或关掉窗口，手机就打不开了。防火墙第一次会弹窗询问，选「允许」。

**乙 · 传文件（完全离线）**
把 `xuanjian-mobile.zip`（约 230 KB）发到手机（微信「文件传输助手」、QQ、USB、网盘皆可），
解压后用浏览器打开其中的 `index.html`。
- Android：文件管理器里长按 `index.html` →「打开方式」→ Chrome / Edge 均可。
- iOS：Safari 不能直接开本地 HTML；用「文件」App 解压后，装一个可开本地网页的 App
  （如 Documents by Readdle）打开 `index.html`，或改用甲、丙两条路。

**丙 · 放到网上（一次部署，处处可用，还能加成 App）**
把整个目录上传到任意静态托管（GitHub Pages / Cloudflare Pages / Netlify / Vercel / 对象存储），
得到 `https://…` 地址。因为站点自带 `manifest.webmanifest` 与 `sw.js`：
- Android Chrome：地址栏右侧「⋮」→「安装应用 / 添加到主屏幕」，之后像 App 一样全屏打开，**断网也能用**；
- iOS Safari：分享 →「添加到主屏幕」，同样全屏离线可用（iOS 16.4 起支持 Service Worker）。

> 说明：`sw.js` 只在 `https://` 或 `localhost` 下生效。用甲法（局域网 `http://`）或乙法（`file://`）时它不会注册，站点照常工作，只是没有离线缓存与「装成 App」这两项。

## 二之二、搜索与问事：怎样「找最相干的答案」

顶栏搜索框、问事页、以及每个模块页尾的「所问何事」输入框，走的是同一套逻辑（`lib/ask.js` + `lib/modern.js`）：

1. **解所问**（`understand`）：从一句话里判出**事项域**（事业、财、婚恋、考试、健康、出行、官讼、失物、子女、家宅、合作、择日、梦兆、测字，共 14 类）、**问法**（能不能／何时／何解／吉凶／如何）与**应期**，并拈出所问之字。
2. **五路取候**（`candidates`）：六爻、梅花、黄历、解梦、测字各自独立起一候，按与所问的关联度打 0–100 分排序；每候写明「为什么给你这一候」。带「梦」者解梦提分，单字或言「测」者测字提分，「哪天／择日／今天／明天」者黄历提分，其余六爻为主、梅花为辅。任一路出错只丢该候，不影响其余。
3. **主答 + 旁参**：主答整段展开（含原有卦爻、断语、依据），旁参收进折叠项，并注明「只作旁类备参」。
4. **现代解释**（`XJModern.explain`）：三段，各 60–140 字——**你问的是**（把白话译成术数的问法）、**术数上看**（这一候的关键数字与原文结论）、**放到今日说**（可做的一两步，附一句「你若只取一句话，就取……」），末尾另附该术的限度声明。**这一层是白话转写，不是古籍原文。**

同样的「现代解释」框也出现在八字、六爻、梅花、紫微、河洛、手相、面相、解梦、测字各页结果末尾，内容取自该页结果本身（日主、格局、用神、卦名、用神爻、分数等），与上文断语逐条对应。

## 三、算法要点（可复核）

**历法**（`assets/js/lib/calendar.js`）
- 节气：Meeus《天文算法》第 25 章太阳视黄经（含光行差、章动近似），牛顿迭代求 15° 整倍数时刻，`ΔT` 用 NASA 多项式。
- 干支：儒略日数定日柱（锚点：1949-10-01 为甲子日），年柱以**立春**换年，月柱用**五虎遁**、时柱用**五鼠遁**，月令以**节**（非中气）为界。
- 真太阳时：均时差 `9.87sin2B − 7.53cosB − 1.5sinB` + 经度时差。
- 建除十二神：月支与日支相对位置；黄道六神为除、危、定、执、成、开。

**四柱**（`bazi.js`）
- 五行力量：天干权重（年 1.0 / 月 1.2 / 日 1.0 / 时 1.0）、地支权重（年 1.0 / **月 2.5** / 日 1.2 / 时 1.0），地支按藏干比例分摊（三藏 0.6/0.25/0.15，二藏 0.7/0.3）。
- 用神三路：**扶抑**（同党占比定强弱）、**格局**（《子平真诠》月令取格 + 相神）、**调候**（冬火夏水，寒暖为急）；候选取用须 `占比 + 透干4 + 有根3 ≥ 6`，避免取到气绝之五行。
- 从格/专旺：同党 ≤18% 且日主无根 → 从格；≥82% → 专旺。
- 大运：阳男阴女顺、阴男阳女逆，**三日折一年**（差值天数 ×4 个月）。

**六爻**（`liuyao.js`）
- 八宫卦序由「本宫→逐爻变→游魂→归魂」生成，世应定位；纳甲用京房纳甲表；六神依日干起；旬空取日柱旬空。
- 断卦以月建、日辰为主，兼看动爻、变爻回头生克、用神持世、世应生克、六冲六合、旬空；用神不上卦则取本宫纯卦同位为**伏神**。

**梅花**（`meihua.js`）
- 先天数 1乾 2兑 3离 4震 5巽 6坎 7艮 8坤；上卦＝(年支数+月+日) mod 8，下卦＝再加时支 mod 8，动爻＝总数 mod 6。
- 体用：动爻所在为用、另一为体；互卦取 2·3·4 与 3·4·5 爻；变卦动爻取反。

**紫微**（`ziwei.js`）
- 命宫 `(2+(月−1)−时支) mod 12`，身宫 `(2+(月−1)+时支) mod 12`；五行局取命宫干支纳音。
- 安紫微：`q=⌈日/局⌉`，`r=q×局−日`，`pos=2+q−1`，`r` 偶顺行、奇逆行；天府 `(4−紫微) mod 12`。
- 十四主星按紫微系、天府系相对位置安放；四化依年干。

**测字**（`cezi.js` + `data/hanzi.js`）
- 形数：笔画取 Unicode Unihan 所载康熙笔画（9,159 字，含常用繁体）；笔画归河图数「一六水、二七火、三八木、四九金、五十土」，逾十取尾（遇十不用）。
- 部首：按康熙二百一十四部取部首与部外笔画，以部首为「主」（所问之正事）、余笔为「宾」。
- 十法：装头、接脚、穿心、包笼、破解、添笔、减笔、对关、摘字、观梅。本站只施**可程式化**者——添笔减笔依 46 组客观字形增损（大→太/天、田→由/甲/申、口→日/中/困/国 等），对关依 46 组相对字（上下、天地、明暗、未末、己已、戊戌、士土…），观梅数笔画定河图五行与阴阳。
- 计分：基准 50，月建生克（他生我 +12／比和 +9／我生他 −6／我克他 −5／他克我 −12）、日干生克（+7／+5／−4／−3／−8）、部首吉凶、字义吉凶 ±6、添减笔所见之字吉凶 ±4、对关反观 −4、所问亲和（五行 +6／部首 +4）；夹于 0–100。

**河洛**（`heluo.js`）
- 天干配河图数（木三八、火二七、土五十、金四九、水一六，阳干取奇阴干取偶），地支配洛书数（子1亥6、巳7午2、寅3卯8、申9酉4、辰戌5、丑未10）。
- 天数＝奇数之和，地数＝偶数之和；天数除 25、地数除 30 取余；「遇十不用」；数→卦「一坎二坤三震四巽五寄宫六乾七兑八艮九离」。
- 阳男阴女天卦在上（余类推）；先天卦六爻俱变、内外互移得后天卦。

## 四、数据来源与校验

- **六十四卦**（`data/hexagrams.js`）：卦辞、彖、象、386 条爻辞（含乾坤用九用六）逐卦取自维基文库 `周易/<卦名>` 原文，经传合计 13,848 字；已校验 64 个 `binary` 互异且覆盖全部六位组合（排除上下卦错位）、卦序符号 = U+4DC0+(n−1)、爻名与阴阳位一致。
- **周公解梦**（`data/dreams.js`）：382 条、863 关键词，其中 310 条为七言歌诀原文，逐字取自通行本《周公解梦》；每条标明「原典 / 通行 / 演绎」，不混原文与演绎。
- **道德经**（`data/daodejing.js`）：王弼本八十一章、5,297 字，取自维基文库并剔除王弼注文（第 45 章源页掺入的他本异文已改回通行本）。
- **农历**（`lib/lunar.js`）：1900–2100 共 73,384 天，已与 lunar-javascript 逐日交叉验证一致。
- **汉字形数**（`data/hanzi.js`）：自 Unicode Unihan 数据库生成，收 GB2312 一二级 6,763 字 + 常用繁体 2,396 字，共 9,159 字。
- **测字文献**（`data/cezi-text.js`）：十法释义与 21 条字例引文逐字取自殆知阁整理本《测字秘牒》（清·程省）；《神机相字法》原书已佚，仅存《四库全书总目》卷一一一之提要，故只据提要作三条通说，**不引正文、不冒充原书**。

## 五、诚实的边界

1. **节气误差数分钟**：视黄经算法精度约 1 角分，实测 2024 年各节气与官方值差 2–9 分钟。恰在交节前后数分钟出生者，月柱可能与官方万年历不同，页中已提示。
2. **紫微亮度**：诸星「庙旺利陷」传本互异（《全书》与《全集》即不同），本站不冒充一家之表，改以**星曜五行 × 宫位五行**生克判得地，星名后注明，页中亦明言属推演。
3. **河洛元堂**：原法于阴阳时、重数、乾坤特例皆有细例，本站取简法（依生时阴阳择爻），页中已注明「只作参考」。求数之法传本亦有出入（有以天干配洛书者、有专用太玄数者），页中列出全部过程并说明所依。
4. **相术**：只有《冰鉴》两句加引号为可查原文（「一身精神，具乎两目；一身骨相，具乎面部」「目者面之渊，不深则不清；鼻者面之山，不高则不灵」），其余一律标「相书通说」，不冒充某书原句。
5. **解梦**：属民间辑本系统，非严格经典，页中标「原典/通行/演绎」三档并注明版本。
6. **测字**：十法原书多有「随手增损、非概然可套」之语，本不可机械套用。本站只把可程式化的部分如实算出；所书之人的神情、字迹工拙、旁物之触机，无法代劳。一字多音、繁简异体，形数随版本亦略有出入。
7. **现代解释**：`lib/modern.js` 的三段白话是把已算出的结论转写成今语，属**编者之译**，不是古籍原文。
8. 命理为象数之学，非科学预测。凡涉疾病、诉讼、投资、婚姻之决断，请咨询专业人士。

## 七、如何复验

内核与数据都可在 Node 下直接 `require`，无需浏览器（在**本目录**下执行）：

```js
const cal = require('./assets/js/lib/calendar.js');
const bz  = require('./assets/js/lib/bazi.js');
console.log(cal.fourPillars(new Date(1949, 9, 1, 10, 0), {})); // 己丑 癸酉 甲子 己巳
```

## 八、引文与推演的区分约定

- `<em>` 引号内、或标注「出处」的句段 —— **古籍原文**，逐字可查。
- 未加引号而标「依法推演」「相书通说」「依某书之义」者 —— 依经义的推断，**不冒充原文**。
- 每个断语块右下角均有依据行（`《子平真诠·论建禄月劫》` 之类），页尾统一附「关于准确性」声明。
