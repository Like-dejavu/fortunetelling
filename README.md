# 玄鉴 · 依经据典的术数推演

一个**纯静态**的中文术数站点：周公解梦、择日吉凶、四柱八字、六爻纳甲、梅花易数、紫微斗数、河洛理数、手相、面相、《道德经》全文。

设计原则只有一句：**凡推算必列过程，凡引文必标出处，凡属推演必注明方法。**

---

## 一、如何打开

双击 `index.html` 即可，不需要服务器、不需要联网、不需要 `npm install`。

- 全部代码为 ES5 风格的原生 JS，经 `<script>` 直接加载；没有构建步骤，也没有任何外部依赖（字体用系统楷体/宋体回退）。
- 所有计算都在浏览器本地完成，**不联网、不上传任何输入**。推算结果只存在于当前页面内存中，刷新即失。唯一写入本机磁盘的是「我的页面」的查询记录（时间、所问、参数摘要与重放链接），存于浏览器 `localStorage`，可随时单条删除或一键清空，详见「二之二」。

如果浏览器禁止 `file://` 读取本地脚本（少见），在本目录跑一条命令即可：

```
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

> 若想在手机上**安装成 App**、离线可用，见「九、装到手机上」：那需要 `https://` 或 `localhost`，`file://` 双击方式不支持安装，但站点本身照常可用。

**线上托管（GitHub Pages）**：<https://like-dejavu.github.io/fortunetelling/>
源码仓库：<https://github.com/Like-dejavu/fortunetelling> —— `main` 为当前版本，旧版（含测字／问事／现代占卜）备份在 `legacy` 分支。手机浏览器打开线上地址即可「安装应用」或「添加到主屏幕」，支持离线使用。

## 二之一、主界面：一句话直达

首页中央是问句框。写下所问，`assets/js/intent.js` 先按功能名／别名／语义短语打分，再抽取**日期、时刻、时辰、性别、择日事项、梦象、章号、卦数、所问之事**等实体，生成一条带参数的哈希链接（可刷新、可分享），跳过去后由 `views/portal.js` 注册的预填器写入表单并触发提交，页面直接出结果。

| 你可以写 | 去往 | 带过去 |
|---|---|---|
| 我昨晚梦见一条蛇 | 周公解梦 | 自动检索梦象「蛇」 |
| 1990年6月17日 10:30 男，排八字 | 四柱八字 | 日期、时刻、性别，自动排盘 |
| 明天宜嫁娶吗 | 黄历吉凶 | 明日日期 + 择日事项「嫁娶」 |
| 帮我摇一卦，问求财 | 六爻纳甲 | 所问「求财」+ 代为摇卦 |
| 用 3 和 8 起一卦，问谋事 | 梅花易数 | 切到数字起卦，带入 3、8 |
| 道德经第八章 / 上善若水 | 道德经 | 定位到第八章 |

- 输入时实时列出候选，`↑` `↓` 择术、`Enter` 直达；任意页面按 `/` 回到主界面并聚焦问句框。
- 问句含混时**不擅自决定**，列出几个去处供选择；解析全在本地完成，不上传。
- 到页后顶部有「来路条」，标明因哪句话而来，可一键「换个问法」返回。
- 关键词表、名句→章号表、实体抽取规则都在 `intent.js`，可自行增删。

## 二之二、我的页面：查询记录

顶部导航「我的」，或直接在主界面问「我之前查过什么」。

**记什么**：时间、去往的功能、原始问句、参数摘要、可重放链接。不记录姓名、账号，也不采集输入之外的任何信息。主界面的一句问话与其后目标页的自动填表、自动推算，会合并为**一条**记录（4 秒内的同键事件合并），不会重复刷屏；在功能页单独改参数再提交，则另记一条。

**怎么记**：`assets/js/history.js` 用全局事件委托监听所有推算表单的 `submit`、解梦／道德经的按钮与回车、代为摇卦等交互，**不改动任何功能页**。主界面跳转时另显式记一条带原句的 `ask` 记录。存储为 `localStorage` 键 `xuanjian.history.v1`，上限 300 条；若浏览器禁用本地存储（无痕模式、部分 `file://` 环境），自动退化为内存存储，页面会明确提示「仅存于本次会话，刷新即失」。

**能做什么**：按今天／昨天／更早分组浏览；按问句、功能、摘要检索或按功能筛选；点「重放」连参数回到当时那次推算；单条删除或二次确认后清空；导出 JSON（UTF-8，含 `app/version/exportedAt/items`）。统计卡显示累计、今日、用过的功能数与最常问。

**隐私**：数据只在这台设备的这个浏览器里，不联网、不同步、不跨设备；清除浏览器站点数据即彻底删除。页面底部「关于这些记录」列明了全部边界。

## 三、算法要点（可复核）

**历法**（`assets/js/lib/calendar.js`）
- 节气：Meeus《天文算法》第 25 章太阳视黄经（含光行差、章动近似），牛顿迭代求 15° 整倍数时刻，`ΔT` 用 NASA 多项式。
- 干支：儒略日数定日柱（锚点：1949-10-01 为甲子日），年柱以**立春**换年，月柱用**五虎遁**、时柱用**五鼠遁**，月令以**节**（非中气）为界。
- 真太阳时：均时差 `9.87sin2B − 7.53cosB − 1.5sinB` + 经度时差。
- 建除十二神：月支与日支相对位置；黄道六神为除、危、定、执、成、开。

**四柱**（`bazi.js`）
- 五行力量：天干权重（年 1.0 / 月 1.2 / 日 1.0 / 时 1.0）、地支权重（年 1.0 / **月 2.5** / 日 1.2 / 时 1.0），地支按藏干比例分摊（三藏 0.6/0.25/0.15，二藏 0.7/0.3）。
- 用神三路：**扶抑**（同党占比定强弱）、**格局**（《子平真诠》月令取格 + 相神）、**调候**（冬火夏水，寒暖为急）；候选取用须 `占比 + 透干4 + 有根3 ≥ 6`，避免取到气绝之五行。
- 从格/专旺：同党 ≤18% 且日主无根 → 从格；≥82% → 专旺。
- 大运：阳男阴女顺、阴男阳女逆，**三日折一年**（差值天数 ×4 个月）。

**六爻**（`liuyao.js`）
- 八宫卦序由「本宫→逐爻变→游魂→归魂」生成，世应定位；纳甲用京房纳甲表；六神依日干起；旬空取日柱旬空。
- 断卦以月建、日辰为主，兼看动爻、变爻回头生克、用神持世、世应生克、六冲六合、旬空；用神不上卦则取本宫纯卦同位为**伏神**。

**梅花**（`meihua.js`）
- 先天数 1乾 2兑 3离 4震 5巽 6坎 7艮 8坤；上卦＝(年支数+月+日) mod 8，下卦＝再加时支 mod 8，动爻＝总数 mod 6。
- 体用：动爻所在为用、另一为体；互卦取 2·3·4 与 3·4·5 爻；变卦动爻取反。

**紫微**（`ziwei.js`）
- 命宫 `(2+(月−1)−时支) mod 12`，身宫 `(2+(月−1)+时支) mod 12`；五行局取命宫干支纳音。
- 安紫微：`q=⌈日/局⌉`，`r=q×局−日`，`pos=2+q−1`，`r` 偶顺行、奇逆行；天府 `(4−紫微) mod 12`。
- 十四主星按紫微系、天府系相对位置安放；四化依年干。

**河洛**（`heluo.js`）
- 天干配河图数（木三八、火二七、土五十、金四九、水一六，阳干取奇阴干取偶），地支配洛书数（子1亥6、巳7午2、寅3卯8、申9酉4、辰戌5、丑未10）。
- 天数＝奇数之和，地数＝偶数之和；天数除 25、地数除 30 取余；「遇十不用」；数→卦「一坎二坤三震四巽五寄宫六乾七兑八艮九离」。
- 阳男阴女天卦在上（余类推）；先天卦六爻俱变、内外互移得后天卦。

## 四、数据来源与校验

- **六十四卦**（`data/hexagrams.js`）：卦辞、彖、象、386 条爻辞（含乾坤用九用六）逐卦取自维基文库 `周易/<卦名>` 原文，经传合计 13,848 字；已校验 64 个 `binary` 互异且覆盖全部六位组合（排除上下卦错位）、卦序符号 = U+4DC0+(n−1)、爻名与阴阳位一致。
- **周公解梦**（`data/dreams.js`）：382 条、863 关键词，其中 310 条为七言歌诀原文，逐字取自通行本《周公解梦》；每条标明「原典 / 通行 / 演绎」，不混原文与演绎。
- **道德经**（`data/daodejing.js`）：王弼本八十一章、5,297 字，取自维基文库并剔除王弼注文（第 45 章源页掺入的他本异文已改回通行本）。
- **农历**（`lib/lunar.js`）：1900–2100 共 73,384 天，已与 lunar-javascript 逐日交叉验证一致。

## 五、诚实的边界

1. **节气误差数分钟**：视黄经算法精度约 1 角分，实测 2024 年各节气与官方值差 2–9 分钟。恰在交节前后数分钟出生者，月柱可能与官方万年历不同，页中已提示。
2. **紫微亮度**：诸星「庙旺利陷」传本互异（《全书》与《全集》即不同），本站不冒充一家之表，改以**星曜五行 × 宫位五行**生克判得地，星名后注明，页中亦明言属推演。
3. **河洛元堂**：原法于阴阳时、重数、乾坤特例皆有细例，本站取简法（依生时阴阳择爻），页中已注明「只作参考」。求数之法传本亦有出入（有以天干配洛书者、有专用太玄数者），页中列出全部过程并说明所依。
4. **相术**：只有《冰鉴》两句加引号为可查原文（「一身精神，具乎两目；一身骨相，具乎面部」「目者面之渊，不深则不清；鼻者面之山，不高则不灵」），其余一律标「相书通说」，不冒充某书原句。
5. **解梦**：属民间辑本系统，非严格经典，页中标「原典/通行/演绎」三档并注明版本。
6. 命理为象数之学，非科学预测。凡涉疾病、诉讼、投资、婚姻之决断，请咨询专业人士。

## 七、如何复验

内核与数据都可在 Node 下直接 `require`，无需浏览器（在**本目录**下执行）：

```js
const cal = require('./assets/js/lib/calendar.js');
const bz  = require('./assets/js/lib/bazi.js');
console.log(cal.fourPillars(new Date(1949, 9, 1, 10, 0), {})); // 己丑 癸酉 甲子 己巳
console.log(bz.analyze({ date: new Date(1990, 5, 17, 10, 30), gender: '女' }).sections[0].body);
```

`_qa/` 下另有一套假 DOM 冒烟测试（沙箱内浏览器不可用时的替代），在**本目录**执行：

```
node _qa/smoke.cjs         # 13 页渲染 + 检索 + 断言（当前 0 problems）
node _qa/test-portal.cjs   # 主界面问句 → 跳转 → 自动填表 → 出结果 → 历史合并（当前 0 problems）
node _qa/test-history.cjs  # 历史：持久化、去重、埋点、统计导出、容量、降级（当前 0 problems）
node _qa/dump.cjs          # 导出每页 HTML 到 _qa/page-*.html 供人工比对
node _qa/peek.cjs          # 去标签打印正文
node _qa/audit-classes.cjs # 页面用到的 class 是否都已定义（查样式遗漏）
node _qa/audit-ziwei.cjs   # 紫微盘 13 格与十二宫方位定位
node _qa/audit-svg.cjs     # 掌图/面相图坐标是否越出 viewBox
```

> 本环境沙箱禁止命名管道，Chromium/Edge 的 headless 一律 `Check failed` 退出，故**没有做过真实浏览器截图**：以上为结构级验证（渲染无异常、无 `undefined/NaN`、class 无遗漏、坐标在框内）。若你在浏览器中看到版式异常，多为 CSS 细节，可直接改 `assets/css/style.css`。

## 八、引文与推演的区分约定

- `<em>` 引号内、或标注「出处」的句段 —— **古籍原文**，逐字可查。
- 未加引号而标「依法推演」「相书通说」「依某书之义」者 —— 依经义的推断，**不冒充原文**。
- 每个断语块右下角均有依据行（`《子平真诠·论建禄月劫》` 之类），页尾统一附「关于准确性」声明。

| 文件 | 作用 |
|---|---|
| `manifest.webmanifest` | 应用名、图标、`standalone` 全屏、主题色、三个长按快捷方式（问一句／我的记录／解梦） |
| `sw.js` | Service Worker：在线优先并后台更新缓存，断网时读缓存；预缓存 34 个资源约 561 KB |
| `assets/img/*.png` | 192 / 512 / maskable 512 / Apple 180 四种应用图标 |
| `index.html` | 清单与 iOS 元信息、`beforeinstallprompt` 安装按钮、SW 注册 |
| `style.css` | 独立窗口下避让刘海与底部手势条（`env(safe-area-inset-*)`） |

**唯一前提：必须通过 `https://` 或 `localhost` 访问。** `file://` 双击打开依旧能正常用，但浏览器不允许注册 Service Worker，也不能「安装」。少数静态服务器不认识 `.webmanifest`，会返回 `application/octet-stream` 导致装不上，给服务器加一条 MIME 映射 `application/manifest+json` 即可（本机 `python -m http.server` 已正确返回）。先在本地验证：

```
python -m http.server 8000     # 然后访问 http://localhost:8000/
```

### 9.2 手机上安装（无需应用商店、无需开发者账号）

- **Android / Chrome**：用手机浏览器打开 HTTPS 地址 → 菜单「安装应用」或「添加到主屏幕」；支持 `beforeinstallprompt` 的浏览器会在右下角出现本站的「安装到手机」按钮。安装后有独立图标、全屏无地址栏、可离线使用。
- **iPhone / Safari**：打开 HTTPS 地址 → 分享 → 「添加到主屏幕」。同样全屏、离线可用（iOS 不触发安装按钮，需手动添加）。

> 装好后，「我的页面」的查询记录存在该应用自己的存储里；卸载即清除，与桌面浏览器不互通。

### 9.3 要真正产出一个可分发、可下载的 `.apk`

两条路，都基于上面这套 PWA 资源：

**A. Capacitor（推荐，不需要先上线，纯本地 WebView 打包）**

在**本目录**（`D:\WorkWork\玄鉴网站`，即 `index.html` 所在目录）执行：

```
npm init -y
npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "玄鉴" com.xuanjian.app --web-dir=.
npx cap add android
npx cap sync
cd android && gradlew.bat assembleDebug
```

产物 `android/app/build/outputs/apk/debug/app-debug.apk` 拷到手机、允许「未知来源」即可安装。正式发布再用 `keytool` 生成签名并配置 `signingConfig` 打 release 包。

**B. Bubblewrap / TWA（更轻，但要求先有线上 HTTPS 域名）**

```
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://你的域名/manifest.webmanifest
bubblewrap build
```

需在线上放 `/.well-known/assetlinks.json` 做域名与签名校验，否则会显示浏览器地址栏。

**本机现状**：Node 22 + npm 10 + JDK 17 已具备；**缺 Android SDK**（`cmdline-tools`、`platforms;android-34`、`build-tools;34.0.0`）、缺 `ANDROID_HOME` 环境变量、缺 `adb`。Gradle 由 Android 工程的 Wrapper 自带，无需单独安装。装好 SDK 并 `sdkmanager --licenses` 接受许可后，上面的命令即可编译。

### 9.4 iOS 与小程序

- **iOS**：Windows 无法产出 `.ipa`，必须 macOS + Xcode + Apple Developer 账号（年费）或 TestFlight；个人使用走 9.2 的「添加到主屏幕」即可，无需账号。
- **微信小程序**：需 AppID + 微信开发者工具。本项目是原生 DOM + 哈希路由，不能直接当小程序跑，通常改用 `web-view` 组件加载已上线的 HTTPS 页面。

### 9.5 更新时记得改版本号

`sw.js` 采用「在线优先」不会让用户卡在旧版；但**改动静态资源后请把首行 `CACHE` 从 `xuanjian-v1` 递增**，否则旧缓存不会被主动清理。
